# Galaxies · Creative Intelligence

Uma ferramenta para comparar criativos antes da publicação, com modelo estatístico,
intervalos de predição e evidências verificáveis.

**Em construção:** implementação por etapas, com dados sintéticos separados da validação real.

## Ambiente

```sh
uv sync --group dev
```

Python 3.12. FFmpeg é necessário para processar vídeos locais.

O repositório não inclui dados de clientes, credenciais ou arquivos do briefing.
